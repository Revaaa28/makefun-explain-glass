One sentence a house cat would say in its own defence in the five seconds after knocking a glass off the table, for make.fun's "Five Seconds to Explain the Glass" bounty. The program writes the cat's excuse — its tail ran a routine sweep at 02:47, found a glass in a no-glass zone, and filed no report, because the floor ate the evidence — to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```
